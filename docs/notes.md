# Buck 小信号模型与 Bode 图推导笔记

> 本文只推导本项目 Python 代码中实际使用的公式，并明确列出简化假设。
> 所有数据为仿真合成数据，不是实测数据。

## 1. 平均状态空间模型

在连续导通模式（CCM）、理想开关、输入电压恒定的假设下，Buck 功率级的
平均模型为（忽略 ESR 时 `v_o = v_C`）：

```
di_L/dt = (d · Vin - v_o) / L
dv_C/dt = (i_L - v_o / R) / C
v_o     = v_C
```

其中 `d ∈ [0,1]` 是占空比。稳态工作点为 `D·Vin = V`，`I = V/R`。

本项目 `plant.py` 用四阶 Runge–Kutta（RK4）以固定步长 `dt` 积分这两个
状态；可选 ESR 用准静态近似 `v_o = (v_C + ESR·i_L) / (1 + ESR/R)`。

## 2. 小信号线性化

令 `d = D + d̂`，`i_L = I + î`，`v_o = V + v̂`，代入并减去稳态方程：

```
dî/dt = (Vin · d̂ - v̂) / L
dv̂/dt = (î - v̂/R) / C
```

零初始条件下取拉普拉斯变换：

```
s·L·Î  = Vin·D̂ - V̂
s·C·V̂ = Î - V̂/R   ⇒   Î = V̂·(C·s + 1/R)
```

消去 `Î`：

```
s·L·V̂·(C·s + 1/R) = Vin·D̂ - V̂
V̂ · [L·C·s² + (L/R)·s + 1] = Vin·D̂
```

于是**控制量到输出**的传递函数为：

```
              Vin
G(s) = ─────────────────────────
       L·C·s² + (L/R)·s + 1
```

这正是 `frequency.py` 中在 `s = jω` 处求值的表达式：

```
|G(jω)| = Vin / sqrt( (1 - L·C·ω²)² + ((L/R)·ω)² )
∠G(jω) = -atan2( (L/R)·ω , 1 - L·C·ω² )
```

幅值以 `20·log10|G|` 转为 dB，相位转为度，在 10 Hz – 100 kHz 之间取 60 个
对数间隔频点。

## 3. 谐振频率与阻尼

化为标准二阶形式 `s² + 2ζω₀s + ω₀²`：

```
ω₀ = 1 / sqrt(L·C)
ζ  = sqrt(L/C) / (2·R)
Q  = 1 / (2ζ) = 2·R·sqrt(C/L)
```

当 `ζ < 1/√2` 时存在幅值峰值，峰值频率：

```
ω_r = ω₀ · sqrt(1 - 2ζ²)
```

默认参数 `Vin=12, L=100µH, C=220µF, R=5Ω`：

```
f₀ = 1/(2π√(LC)) ≈ 1073 Hz
ζ  ≈ 0.0674,  Q ≈ 7.4
f_r ≈ 1068 Hz
```

这与 CLI 输出的“resonance estimate ≈ 1068.1 Hz”一致；数值扫描得到的峰值
频率（≈1081 Hz）落在同一对数频点附近。

## 4. 为什么要看 Bode 图

- **稳定裕量**：环路增益穿越 0 dB 时的相位决定相位裕量；增益裕量反映
  接近不稳定程度。PID 增益不能只看阶跃响应。
- **谐振峰**：低阻尼 LC 输出滤波器在 `f_r` 附近有高增益峰，容易放大
  开关纹波和测量噪声，需要补偿器提供阻尼。
- **带宽取舍**：闭环带宽要足够快以跟踪负载变化，又要远低于开关频率和
  采样频率，否则采样延迟与 PWM 延迟会破坏相位裕量。
- **补偿器设计**：PID 的零点/极点位置正是依据被控对象的幅相曲线选取。

注意：本项目的 Bode 图是**开环被控对象**（控制量占空比 → 输出电压），
不包含 PID 闭环，也不包含采样保持和 PWM 延迟；它用于理解和教学，不能
替代真实环路分析仪的测量。

## 5. 简化假设（诚实声明）

- 理想开关、平均模型：忽略开关纹波、死区、导通压降与开关损耗。
- 仅 CCM：轻载跳周期 / DCM 未建模。
- `Vin` 恒定，无输入扰动与线路调整率建模。
- 解析 Bode 忽略 ESR 与输出电容的等效串联电感（但时域 plant 支持可选 ESR）。
- 无 ADC 量化/噪声、无采样保持、无计算与 PWM 更新延迟。
- 无保护、软启动、限流等真实固件必备功能。

因此本仓库的所有响应都是**理想合成数据**，不代表任何真实硬件的测量结果。
